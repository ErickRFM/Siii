# SIII V4 — Matriz de roles y capacidades

| Rol | Estado | Capacidades | Notas |
|---|---|---|---|
| Estudiante | PARCIAL | Perfil, expediente, materias, calificaciones publicadas, historial, finanzas, solicitudes, avisos | Foco prioridad 1 |
| Docente | PARCIAL | Materias/grupos, captura calificaciones, publicación autorizada, borradores | Foco prioridad 2, no acceso cruzado |
| Aspirante | DESCONOCIDO/AUDITAR | Por descubrir | Verificar |
| Caja | PARCIAL | Órdenes, pagos, conciliación (superficies) | Sin sumar monedas distintas |
| Control Escolar/Servicios Escolares | PARCIAL | Trámites, documentos | Por certificar |
| Admisiones | PARCIAL | Solicitudes/aplicaciones | Datos reales |
| Coordinación | PARCIAL | Supervisión por alcance | Por roles/capacidades |
| Dirección | PARCIAL | Supervisión | Por roles/capacidades |
| Administración | PARCIAL | Gestión institucional | Por roles/capacidades |
| Superadministración | PARCIAL | Configuración | Privilegio mínimo |
| Tutor Institucional/Invitado | POSIBLE | Solo si contrato lo requiere | Diferenciar si aplica |

Nota: usar capacidades (permissions/scopes), no solo ocultación UI.
